Dijkstra’s algorithm (beginner)

Shortest paths in a weighted graph with non-negative edge weights. Same spirit as your guide: dist[v] = min(dist[v], dist[u] + weight) — we repeatedly pick the closest unknown vertex and relax its outgoing edges.

Walkthrough (read once, then use Step below)

  1. Initialize — set dist[source] = 0 and all other distances to “infinity”. Nothing is settled yet.
  2. Pick — among vertices that are not settled, choose u with the smallest tentative distance. If the smallest is still infinity, stop.
  3. Settle — mark u as settled. Its shortest distance from the source is now final (that is why weights must be ≥ 0).
  4. Relax — for each neighbor v of u, try dist[u] + w. If that is smaller than dist[v], update dist[v] and remember parent[v] = u for path reconstruction.
  5. Repeat pick → settle → relax until every vertex is settled or only unreachable ones remain.

This demo uses the simple O(V²) “scan all vertices” pick — perfect for learning. A priority queue is the standard upgrade for sparse graphs.
